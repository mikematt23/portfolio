
# 🧑‍💻 Michael Matteis — Developer Portfolio

This is my personal web developer portfolio — a responsive site built with **HTML**, **CSS**, and **JavaScript** to showcase my projects, skills, and background. It’s a simple but effective way to demonstrate what I can build from scratch without relying on frameworks.

---

## ✨ Features

- 📄 Personal bio and developer mission  
- 💼 Project showcase with GitHub links  
- 🧠 Technical skills and tools list  
- 📫 Contact information and call to action  
- 📱 Fully responsive layout for mobile and desktop

## 🛠️ Setup Instructions

1. **Clone the repo**
   ```bash
   git clone https://github.com/mikematt23/portfolio.git
   cd portfolio
   ```

2. **Open the site locally**
   Just open the `index.html` file in your browser:
   ```bash
   open index.html   # macOS
   # or
   start index.html  # Windows
   ```
